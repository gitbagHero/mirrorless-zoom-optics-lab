# Mirrorless Zoom Optics Lab

## 微单变焦镜头中镜组成像与变焦对焦原理演示

一个以 **NIKKOR Z 24-200mm f/4-6.3 VR** 为研究案例的交互式光学教学项目。

目标是把一支高倍率变焦镜头拆成可以观察、可以操作、可以解释的几层：

- 19 片镜片的侧视结构；
- 六组镜片在变焦时如何分工和移动；
- G5 内对焦组如何完成手动对焦与自动对焦；
- G5 对焦组如何在不同对焦距离下向像方移动；
- ED / 非球面 / 非球面 ED 分别在解决什么问题。

**在线演示：** <https://gitbaghero.github.io/mirrorless-zoom-optics-lab/>

> 当前版本：`v1.0.0`。I0–I6 全部完成：结构、光路、变焦、对焦、导览与发布硬化。

**发布说明：** [docs/release-notes-v1.0.md](docs/release-notes-v1.0.md)

## 项目边界

本项目是**基于尼康公开专利实施例与官方规格的教学示意模型**：

- 不是尼康官方光学仿真；
- 不是量产镜头的精确 CAD；
- 不使用官方营销图，结构视觉素材由项目重绘；
- 专利实施例 8 用于近似 19 片 15 组的六组结构，但与量产版存在差异（例如专利焦距 24.7–194 mm、光圈 f/4.12–6.49）；
- 所有光学运动、像差和成像反馈都应在页面中明确标注“示意”。

NIKKOR 与 Nikon 是 Nikon Corporation 的商标。本项目是非官方、非商业的教学演示，不暗示尼康背书。

## v1.0 能力

### 起始页与单窗口应用壳

- 独立全屏起始页：主标题、说明、纯镜组蓝图剖面与进入工作台动作；
- 蓝图使用工作台同一套镜组线框语言，点击后过渡到工作台；
- 应用内左侧菜单切换四个主模块：工作台 / 对焦 / 导览 / 数据说明；
- 左侧菜单可折叠为图标栏，状态会记住；
- 工业蓝图主题：深海军蓝底、青色制图网格、单色线框与等宽标注；
- 同一时间只显示一个主模块，不再纵向铺成长页面；
- 工作台右侧通过“结构说明 / 变焦运动”子面板切换，两者共用同一栏；
- 工作台剖面可显示半透明外壳，前筒 1.0× / 中筒 0.65× 同步前移，筒长固定；
- 导览改为章节阅读器，一次只读一章；
- 数据说明底部显示项目仓库地址。

### 结构与分组

- 19 片 / 15 组镜片侧视结构，按专利半径绘制形状；
- G1–G6、光圈、像面的功能分区与组括号；
- “19 片结构 / 6 组功能”双视图；
- 点击/键盘选择镜片或组，查看形状、nd/νd、类型与作用；
- ED / AS / ASED / VR / FOCUS 标记与推断边界。

### 光路与变焦

- 二维逐面折射：球面 + 非球面、Snell 折射、光圈裁剪；
- 轴上 / 轴外 / 光线扇三种预设，支持显示光线开关；
- 24–200 mm 变焦滑杆，四锚点平滑插值；
- G3 / G6 / 光圈整体块约束，D4 非单调保留；
- “变焦时谁在动”面板：G1–G6 行程与同步关系；
- EFL(∞)：24.70 / 50.00 / 105.00 / 194.00 mm 与专利表 8 对齐。

### 对焦与成像

- G5 内对焦，行程约 1.31–9.53 mm；
- 手动对焦环、AF-S 单次对焦、AF-C 连续追焦；
- 远景 / 主体 / 近景目标与目标距离；
- G5 对焦组位移图：当前/目标位置、归一化行程与 mm 读数；
- 有限物距光线追迹：对焦位置改变像面处的光线会聚。

### 导览与发布

- 六章“从操作到原理”导览，每章带 Try this 状态预设；
- 术语速查、来源与模型边界说明；
- 数据说明底部标注项目仓库地址；
- 响应式 1920 / 1365 / 768 / 390；
- 键盘主路径、减少动态、ARIA 状态；
- Vitest + Playwright；
- GitHub Pages 自动部署。
