# Mirrorless Zoom Optics Lab v1.0.0 发布说明

- 发布日期：2026-10-19
- 分支：`dsh-dev`
- 线上地址：<https://gitbaghero.github.io/mirrorless-zoom-optics-lab/>
- 版本标记：`v1.0.0`
- 研究案例：NIKKOR Z 24-200mm f/4-6.3 VR
- 模型基础：US20220121021A1 实施例 8

## 这一版能做什么

- 独立全屏起始页：纯镜组蓝图剖面与进入工作台过渡；
- 单窗口应用壳：工作台 / 对焦 / 导览 / 数据说明；
- 左侧菜单可折叠为图标栏；
- 工作台右侧“结构说明 / 变焦运动”子面板；
- 剖面可开关半透明外壳，前筒 1.0× / 中筒 0.65× 同步前移，筒长固定；
- 导览章节阅读器，一次一章；
- 数据说明底部显示仓库地址；
- 19 片 / 15 组镜片侧视结构；
- G1–G6、光圈、像面的功能分区；
- 19 片结构 / 6 组功能双视图；
- 按专利半径绘制镜片形状；
- 二维子午面光线追迹：球面 + 非球面、Snell 折射、光圈裁剪；
- 轴上 / 轴外 / 光线扇三种光路预设；
- 24–200 mm 变焦滑杆；
- 四锚点平滑插值，G3/G6/光圈整体块约束；
- “变焦时谁在动”组运动面板；
- G5 内对焦、手动对焦环、AF-S / AF-C；
- G5 对焦组位移图：当前/目标位置、归一化行程与 mm 读数；
- 有限物距光线追迹；
- 六章“从操作到原理”导览，每章带 Try this；
- 术语速查、来源与模型边界说明。

## 浏览器说明

- **Chrome / Chromium**：已通过 Playwright 自动化与人工视觉检查。
- **Safari / Firefox**：当前环境没有可用的 Playwright WebKit/Firefox 二进制，Safari 远程自动化也未启用，因此没有完成自动化验证。
- 页面使用标准 SVG / Canvas 2D / CSS / React API，没有依赖 Chromium 专有特性；发布后建议在最新版 Safari 与 Firefox 做一次人工冒烟。

## 已知边界

- 不是尼康官方光学仿真，也不是量产镜头精确 CAD。
- 专利实施例 8 的焦距为 24.7–194 mm、光圈 f/4.12–6.49，页面 UI 用 24–200 mm 做教学映射。
- 光线追迹是二维子午面，不含衍射、镀膜光谱、公差、热漂移和装配误差。
- 对焦映射基于薄透镜近似与专利对焦行程，不是量产镜头的实测控制曲线。
- 对焦组位移图使用归一化行程，便于观察运动；实际位移以 mm 读数为准。
- VR、光圈/景深、像差深化和科普视频导出属于 post-v1.0。

## Post-v1.0

3. 像差/MTF/ED 对比深化。
4. 科普视频/导出模式。
