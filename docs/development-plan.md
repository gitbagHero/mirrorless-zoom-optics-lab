## 2. v1.0 范围

### 2.1 目标

做一个**可直接打开、可操作、可讲解**的镜头光学演示站：

- 看到 19 片镜片的侧视结构和六组功能分区；
- 拖动焦距，看到六组如何移动、谁和谁是一体；
- 控制手动对焦，看到 G5 如何前后移动、像面如何由虚变实；
- 切换 AF-S / AF-C，选择目标，看到“机器对焦”的闭环过程；
- 用合成目标图看到离焦模糊和合焦清晰；
- 通过分章导览理解“为什么需要这些镜片”。

### 2.2 v1.0 包含

1. **结构层**：19 片镜片、15 组、G1–G6、光圈 S、像面、ED/AS/ASED/对焦组标签；VR 子组仅做位置标注，不做交互。
2. **光路层**：二维子午面逐面折射、球面/非球面、光圈裁剪、轴上/轴外光线。
3. **变焦层**：24–200 mm 滑杆、六组运动、G3/G6/光圈一体块、运动箭头、“谁在动”面板。
4. **对焦层**：手动控制、AF-S、AF-C、目标选择、G5 内对焦、合成图像离焦/合焦。
5. **解释层**：分章导览、组/镜片点击解释、“为什么需要”卡片、数据来源与边界说明。
6. **发布层**：响应式、键盘操作、减少动态、GitHub Pages 部署、测试与文档。

### 2.3 v1.0 不包含

- 交互式 VR 防抖演示；
- 交互式光圈/景深/焦外光斑；
- 真实照片上传或真实样片；
- 后端、账号、云端保存；
- 3D/WebGL 镜头模型；
- 视频导出/分镜模式；
- 量产级精确光路、凸轮曲线、玻璃牌号、公差分析。

### 2.4 v1.0 完成定义（Definition of Done）

- 在桌面 1920×1080 和 1365×768 下，主工作台完整可用，标签不重叠。
- 在 768 宽平板上可用；390 宽手机上核心控件可操作、正文可读。
- 19 片/15 组数量、六组名称、G3/G6 块、G5 对焦组、ED/AS/ASED 标记正确。
- 变焦四个锚点的组位置与专利数据一致（误差 ≤ 0.5 mm）。
- G5 对焦行程与专利近距数据一致（误差 ≤ 0.1 mm）。
- 光路无 NaN/Infinity，光线不穿出镜片外轮廓（示意口径内）。
- 手动、AF-S、AF-C 都能改变 G5 位置并驱动图像清晰度变化。
- 所有页面都有“示意模型/非官方”说明和来源入口。
- `pnpm test`、`pnpm build`、Playwright 冒烟全部通过。
- GitHub Pages 可访问，无控制台错误。
- 开发计划状态表已更新，提交已推送到 `dsh-dev`。

### 3.5 视觉方向

- **外壳**：明亮扁平，浅色底、白色实心模块、细彩色边线、扁平偏移底面。
- **主舞台**：深色光学台，作为页面唯一“暗色焦点”；镜片用半透明彩色玻璃，光线用高亮细线。
- **镜片颜色**：按组区分色相；ED/AS/ASED 用角标或小徽标，不靠颜色单独表达。
- **标签**：12px 下限；19 片视图用引线/缩写，6 组视图显示完整组名。
- **动效**：变焦/对焦用短促、可中断的过渡；尊重 `prefers-reduced-motion`。
- **禁止**：玻璃拟态、透明层叠、海报式超大字号、满屏细线。

**测试**

### I2 — 光路引擎

**目标**：用专利实施例 8 的处方做二维示意光线追迹。

**交付物**

- 35 面数据模块（R/D/nd/νd）；
- 球面折射 + 非球面 sag；
- Snell 折射、光线-面交点、光圈裁剪；
- 轴上光线、轴外光线、光线扇预设；
- EFL 计算与单元测试；
- 光线数量/性能开关；
- 光线异常的 graceful fallback。

**验收标准**

- 近轴复算 EFL = 24.70 / 50.00 / 105.00 / 194.00 mm（±0.1 mm）；
- 光线从物方到像面连续，无 NaN/Infinity；
- 光圈外光线被裁掉；
- 50 条光线在桌面端拖动时不明显卡顿；
- 非球面关闭/开启不导致崩溃；
- Canvas 有文字 fallback 说明。

**测试**

- Vitest：EFL、光线交点、非球面 sag、光圈裁剪；
- Playwright：Canvas 出现、光线开关、无控制台错误；

### I3 — 变焦运动

**目标**：把“六组怎么动、谁和谁一体”变成可操作的主交互。

**交付物**

- 24–200 mm 焦距滑杆（含 24/35/50/70/105/135/200 刻度）；
- 六组位置插值（4 个专利锚点）；
- G3/G6/光圈整体块约束；
- D4 非单调插值；
- 运动箭头/行程条；
- “谁在动”面板：组卡片 + 当前行程；
- 焦距变化时组标签、光线、组括号同步。

**验收标准**

- 四个锚点位置与专利一致（±0.5 mm）；
- G3 第一面到 G6 第一面距离恒定（约 61.84 mm）；
- G3/G6/光圈始终同步；
- G4/G5 相对运动不穿模（示意口径内）；
- 滑杆键盘可用（方向键/Home/End）；
- 切换视图/拖动滑杆不重置对焦状态。

**测试**

- Vitest：锚点位置、块约束、D4 插值；
- Playwright：滑杆拖动、键盘、二视图切换；
- 人工视觉：1365/1920 下六组箭头不重叠。

### I4 — 对焦与合成成像

**目标**：把“手动对焦”和“机器对焦”都做成可观察的闭环。

**交付物**

- 手动对焦：滑杆 + 控制环拖拽（示意）；
- G5 向像方移动，行程按 1.31–9.53 mm 映射；
- 对焦距离/放大倍率提示；
- AF-S：单次驱动，轻微过冲后收敛；
- AF-C：连续采样，目标移动时追焦；
- 目标选择：近处卡片 / 远处卡片 / 合成主体；
- 合成目标图 + 离焦模糊/合焦清晰；
- 合焦指示（清晰度条/峰值标记）；
- 重置按钮；
- `prefers-reduced-motion` 下直接切到终态。

**验收标准**

- 手动和自动都能改变 G5 位置；
- AF-S 在有限步内收敛，过冲不超过 2 次；
- AF-C 能跟随目标距离变化；
- 目标切换后 AF 重新收敛；
- 合成图像在合焦时明显更清晰；
- 对焦到 MFD 时不出现负间距/穿模；
- 键盘可操作对焦控件；
- 无控制台错误。

**测试**

- Vitest：对焦行程、目标距离映射、AF 收敛；
- Playwright：MF 拖动、AF-S、AF-C、目标切换；
- 人工视觉：合焦/离焦对比、过冲观感。

### 5.3 每批增量的固定流程

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 专利代理模型与量产不符 | 内容被误解 | 全站标注；来源页写清 24.7–194 / f4.12–6.49；不称“官方光路” |
| 19 片标签拥挤 | 可读性差 | 引线 + 缩写 + 双视图；1365/1920 两档专门调；必要时开关标签 |
| 非球面追迹数值不稳定 | 光线跳变/崩溃 | 输入校验、交点容差、异常光线丢弃、fallback 说明 |
| 变焦插值穿模 | 视觉不可信 | G3/G6 块约束；D4 单调分段/样条；穿模检测 |
| AF 动画显得假 | 教学效果差 | 平滑收敛 + 轻微过冲；显示目标误差；可关闭动画 |
| 暗色舞台与亮色外壳冲突 | 视觉割裂 | 暗色只做“舞台面板”，周围留亮色边框和说明区 |
| 移动端控件拥挤 | 手机不可用 | 桌面优先；手机折叠为“核心滑杆 + 图 + 说明” |
| GitHub Pages 路径 | 资源 404 | Vite `base` 配置；Actions 构建；线上冒烟 |
| 版权/商标 | 发布风险 | 全部重绘；提名使用；免责声明；不搬运官方营销图 |
