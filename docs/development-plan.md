## 光学实现

- 剖面和光路共用一份处方。正式产品标称 24–200 mm，仿真模型采用 WO2020157904A1 参考实施例 12，覆盖约 24.72–194.00 mm。网页展示两种数值及其来源。镜片功能说明按量产图、参考处方和推断依据编写。 [光学调研与处方](nikkor-z-24-200-optics-research.md)
- 固定像面。四个变焦档位使用表列间距，连续位置对独立运动轨迹插值，保持同位移组的联动，再计算有效焦距和光斑。变焦时，MF 保留用户设定的对焦偏移，AF 重新合焦时显示镜组动作。
- 成像计算使用光线与像面的落点。教学测试图按计算的视角与离焦变化。有效口径、光阑开口的估算和连续位置的插值均在界面资料中说明。
- 两种 AF 共用处方和对焦双片。相位检测利用入瞳两侧光束的像面偏移判断调焦方向。对比度检测比较候选位置的局部清晰度，并展示搜索与择优过程。

## 每批验证与同步

1. 开始前核对开发分支、工作区差异和本批验收条件。在本文登记进行中的增量。
2. 运行数值回归、类型检查、生产构建及本批浏览器用例。通过后更新增量验收状态，将成果和计划记录一并提交。
3. 推送开发分支并比对本地提交与远程分支头。记录验收证据、提交标识与同步结果后进入下一批。遇到阻塞则在记录中写明具体错误和未完成项。
4. 第四批从专用仓库 `gitbagHero/mirrorless-zoom-optics-lab-gpt` 的 `gpt-optics-demo` 分支通过 GitHub Actions 发布。默认地址的资源基路径为 `/mirrorless-zoom-optics-lab-gpt/`，构建从 Pages 读取实际路径。最终保存正式 URL 和线上操作验收结果。 [Vite 静态部署](https://vite.dev/guide/static-deploy.html#github-pages) · [GitHub Pages 自定义工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

第一批使用工作区已有依赖构建。四个档位的有效焦距、后焦距和近摄合焦残差上限分别约为 0.000163、0.000145 和 0.000249 mm。浏览器用例包括依次选择 19 片、键盘激活、胶合镜片跳转、剖面点选和手机视口。连接 npm 注册表受限，已核对锁文件的直接依赖版本，尚需在有注册表访问的环境验证全新安装。

第二批按曲面逐面求交并应用 Snell 折射。自动检查覆盖四个专利档位、96 个连续位置的焦距及联动、13 个位置的绘图口径内曲面间隙与轴上、离轴光束。图中显示抽样光线，像面指标按 81 条剖面样本求值。光阑开口由入瞳半径和近轴光线换算，镜片口径采用剖面估计。收小光圈时使用同一入射样本比较通过与裁切。

参考处方的四个专利档位可复算无穷远近轴合焦。连续位置使用分段线性间距插值，可能出现离焦，界面用实时光斑呈现这种变化。取景测试图基于全画幅近轴视角和几何光斑，作为教学预览。

第三批按相对于固定像面的距离设置主体。在同一焦距内，仅面 29–31 随 E16/E17 沿轴移动。向像方的行程上限取参考近摄处方，向物方预留至少 1 mm 的教学行程，用于观察前后离焦及插值档位的对焦补偿。参考四档的近摄位置再次复算，像点的近轴轴向偏差均小于 0.001 mm。

相位法比较光阑正负半边通过的两束光在像面上的平均落点，以位移差的符号与大小引导搜索。对比度法将几何光斑宽度换算为高斯模糊下的线对对比度估计，先采样全行程，再围绕较优样本细化。两者均用当前有限或无穷远物点的光路求值，提供合焦、超出行程和光线不足反馈。AF 启动后，变焦、光圈或主体设置变化会重新测量。

第四批的四个教学场景复用实验台的实际状态。切换场景会载入对应参数，跳过引导保留当前实验，重置则复原焦距、光圈、光束、对焦与 VR 控件。VR 使用独立的理想补偿图，展示 E09/E10 横向移动与参考像点的关系。

发布工作流要求仓库和分支同时匹配专用发布目标。构建阶段读取 Pages 基础地址，若发现原项目地址则终止。部署后把正式 URL 传入 Chromium 验收作业。留待发布后在此记录部署 URL、提交号和 `verify-site` 结果。
